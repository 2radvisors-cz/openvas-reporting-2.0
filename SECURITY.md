# Security Policy

This repository contains product information only and does not contain the product source code or deployment artefacts.

Please do not disclose suspected vulnerabilities publicly through GitHub issues. Report security concerns privately to:

- Email: [info@2radvisors.cz](mailto:info@2radvisors.cz)
- Contact page: [https://www.2radvisors.cz/en/contact/](https://www.2radvisors.cz/en/contact/)

Include a clear description, affected product version or deployment, reproduction information and your preferred contact details. 2R Advisors will acknowledge and assess legitimate reports through an appropriate private channel.
